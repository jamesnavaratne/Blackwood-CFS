# Blackwood CFS v2.5.5 — Dark Neon Surface Consistency

## Scope
Visual-only inventory app refinement.

## Changes
- Hamburger drawer restored to a deep, theme-aware gradient surface.
- Drawer menu cards use restrained gradient depth, neon edging, and stronger active states.
- Collapsed and expanded locker headings use deeper opaque gradients rather than inheriting the lifted group background.
- Existing brighter inventory cards, system home, appliance backgrounds, search behaviour, inventory data, photos, Directions Book, and navigation logic are unchanged.

## Deployment
The service-worker cache key was bumped so the updated CSS is refreshed after deployment.
