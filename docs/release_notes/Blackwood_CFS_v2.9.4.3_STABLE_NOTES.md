## Inventory collapse indicators

Collapsible Inventory locker/group headings now use one standard convention:

- `+` means collapsed and can be expanded;
- `−` means expanded and can be collapsed.

The Inventory Home Expand All / Collapse All control uses the same glyphs. Collapse state, click/keyboard handling, filtering and saved Inventory workspace behaviour are unchanged.
