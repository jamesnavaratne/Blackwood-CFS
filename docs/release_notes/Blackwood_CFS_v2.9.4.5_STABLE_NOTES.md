# Blackwood CFS v2.9.4.5 Stable — 2026-09-29

This release consolidates all verified v2.9.4.4 work into one clearly identified stable package.

Included changes:

- Installed-PWA tablet landscape support.
- Three-column Inventory layout in tablet landscape.
- Side-by-side Directions and UBD layout with a fixed-width 640px Directions card.
- Immediate touch and mouse drag/pan at the opening 100% UBD view.
- Persistent full-width taskbar with independent Inventory, Directions Book and Hydrants workspace restoration.
- Reverse-order outside-click closing for the Directions and UBD modal stack.
- Consistent Inventory `+` and `−` collapse indicators.
- Simplified Hydrants heading showing only `Blackwood CFS` and `Live Hydrants`.
- Mobile Directions alphabet rail positioned below the full rendered header.
- Inventory hamburger drawer ending above the persistent taskbar.

The user-facing version, release metadata and service-worker cache identity now identify `v2.9.4.5 Stable`. All existing inventory data, Directions entries, UBD maps, Hydrants coordinates, offline preparation and workspace-persistence behaviour are preserved.
