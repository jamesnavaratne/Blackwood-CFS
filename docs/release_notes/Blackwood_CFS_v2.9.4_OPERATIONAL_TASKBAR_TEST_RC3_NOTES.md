## Operational workflow

The taskbar remains visible and tappable above the complete modal stack. A user can:

1. Search for and select a Directions entry.
2. Open a UBD map from that street modal.
3. Switch directly to the live Hydrants page.
4. Pan the hydrant map or use live location.
5. Return through the Directions Book taskbar tab.
6. Continue with the same street modal and UBD viewer at the saved map, zoom and pan position.

## State retained during the current app session

- Selected Directions entry.
- Directions search text and street-modal scroll position.
- UBD list/viewer open state.
- UBD map selection.
- UBD zoom and relative pan position.
