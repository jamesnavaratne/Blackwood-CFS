# Blackwood CFS v2.7.0 Navigation Polish RC1

Built from the accepted v2.6.2 inventory-update baseline.

## Changes
- Dark initial paint and theme handoff for Directions Book navigation.
- More permissive locker swipe travel with progressive destination arrow.
- Locker ribbon scrolling is now contained within the ribbon and no longer uses viewport-level `scrollIntoView`.

## Preserved
- Excel as the inventory source of truth.
- All appliance photos and Directions source/map assets.
- Full item-modal In service / Out of service controls.
- Accepted visual themes and hamburger menu styling.
