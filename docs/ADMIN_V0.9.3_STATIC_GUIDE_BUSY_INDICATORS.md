# Admin v0.9.3 — Clear publishing instructions

- Replaced unreliable live numbered-step progression with a stable, manual seven-step publishing guide.
- Retained the latest PR number and Copy number action; a successfully submitted PR remains highlighted green regardless of GitHub status availability.
- Publishing instructions are collapsible, defaulting closed on screens up to 1000px wide; the fixed mobile footer prioritises the latest PR and Copy number.
- Standardised button loading indicators for GitHub sign-in, connection checking, submission and sign-out, with a matching checking indicator in the header.
- Kept inventory editing, photo changes, proposal submissions and reconciliation code unchanged.
- No Cloudflare redeployment required.
- This guide does not claim to track workflow approval or deployment automatically. Use GitHub checks and the live app to verify publication.
