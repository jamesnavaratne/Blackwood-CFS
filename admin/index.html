1
Save your draft

Edit a record or remove its added photo, then tap Save draft. Check the Draft changes count.

2
Submit to GitHub

Check GitHub login, then select Submit drafts for review. Open the new draft pull request using its link.

3
Process that PR

From Actions → Process Blackwood Admin review proposal → Run workflow, select branch main and enter the new PR number. Wait for success.

Open processing workflow ↗
4
Review generated files

In the PR's Files changed, check the Excel workbook, inventory data, photo additions/removals and admin/processed/ report.

Open pull requests ↗
5
Approve and merge

If GitHub requests workflow approval, approve and wait for green checks. Select Ready for review, then Merge pull request. Never merge a proposal-only PR.

6
Verify volunteer app

Wait for the main branch/Pages deployment, refresh the installed app and confirm the exact item and photograph.
