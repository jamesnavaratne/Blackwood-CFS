Publishing instructions7 steps ▾

Follow these steps in order. They are a reference checklist, not a live progress tracker. Your PR number above stays saved for GitHub Actions.

Pull requests ↗Processing Action ↗
1
Save your equipment edits

Make the changes, then select Save draft. Nothing is published yet.

2
Submit draft to GitHub

Sign in with GitHub at the top if needed, then choose Submit drafts for review. Keep the new PR number.

3
Run processing Action

Go to Actions → Process Blackwood Admin review proposal → Run workflow. Use branch main and enter the new PR number. Wait for a green success.

Run processing ↗
4
Approve workflow if requested

Return to the PR. If GitHub says Workflow awaiting approval, select Approve workflows to run and wait for checks to finish. Otherwise continue.

5
Review processed changes

In Files changed, check the Excel master, inventory data, photo changes and admin/processed/ report. Validation must be green.

6
Ready for review → Merge

When files are correct and checks have passed, select Ready for review, then Merge pull request and confirm.

7
Confirm volunteer app update

Check the Pages deployment under Actions; refresh Blackwood CFS and verify the edited item and photograph.

Open live app ↗
